# memori — v2 (iOS 네이티브)

삶의 모든 것을 단 하나의 단위, **남은 시간**으로 보여주는 앱. 기획은 [`docs/memori-v2/prd.md`](../../docs/memori-v2/prd.md)의 "제품 코어: 남은 시간 렌즈"를 따릅니다.

- **언어·프레임워크:** SwiftUI, SwiftData, WidgetKit
- **최소 버전:** iOS 17
- **외부 의존성:** 없음
- **데이터:** 모두 기기 안에만 저장합니다. 서버도, 광고도, 추적도 없습니다.

## 빌드하기

1. XcodeGen을 설치합니다.
   ```sh
   brew install xcodegen
   ```
2. 식별자를 본인 것으로 바꿉니다. 아래 두 곳에 있는 `com.yourcompany`를 본인의 리버스 도메인으로 교체하세요.
   - `project.yml`: 번들 ID 2개, 앱 그룹 2곳
   - `Shared/Profile.swift`: `AppGroup.id`
   - 그리고 `project.yml`의 `DEVELOPMENT_TEAM`에 Apple 개발자 팀 ID를 넣습니다.
3. 프로젝트를 생성하고 엽니다.
   ```sh
   cd apps/memori
   xcodegen
   open Memori.xcodeproj
   ```
4. `Memori` 스킴으로 실행합니다. 테스트는 `⌘U`로 돌립니다.

`.xcodeproj`, `Info.plist`, `.entitlements`는 `project.yml`에서 생성되므로 커밋하지 않습니다. 설정을 바꿀 때는 `project.yml`을 고친 뒤 `xcodegen`을 다시 실행하세요.

## 구조

```
apps/memori/
├── project.yml          XcodeGen 설정 (앱, 위젯, 테스트 타깃)
├── Shared/              앱과 위젯이 함께 쓰는 코드
│   ├── LifeMath.swift   모든 숫자 계산 (남은 주, 남은 만남, 노동 시간)
│   ├── Profile.swift    앱 그룹 UserDefaults, 위젯용 스냅샷
│   └── Theme.swift      색(알루미늄·월넛·잉크), 서체, 공통 스타일
├── Memori/              앱
│   ├── Models/          Person, WishItem (SwiftData)
│   ├── Services/        로컬 알림, 위젯 갱신
│   └── Views/           시간 · 사람 · 돈 탭, 온보딩, 설정, 공유 카드
├── MemoriWidget/        홈 화면 위젯과 잠금화면 위젯
└── MemoriTests/         LifeMath 단위 테스트
```

## v2.0 출시 범위 대비 구현 현황

| PRD 항목 | 상태 | 구현 내용 |
|---|---|---|
| 남은 주 홈 | ✅ | 생년월일 하나로 시작. 남은 주, 남은 여름, 인생 달력(한 점 = 한 주) |
| 사람 | ✅ | 사람 추가(이름, 나이, 연간 만남 횟수) → 남은 만남. "오늘 만났어요"를 누르면 숫자가 하나 줄고 묵직한 햅틱이 옴. 다음 만남 날짜와 전날 알림 |
| 돈 | ✅ | 가격 → 노동 시간 → 남은 깨어 있는 시간의 %. "7일 뒤 다시 묻기" 알림 후 "그래도 산다 / 보내준다"로 결정. 보내준 것은 "되찾은 시간"으로 쌓임 |
| 위젯 | ✅ | 홈 화면 소형, 잠금화면 인라인·원형·직사각형. 남은 주와, 다음 만남이 가장 가까운 사람 |
| 공유 카드 | ✅ | 남은 여름, 남은 만남, 물건의 시간값을 이미지로 공유 |
| 설정 | ✅ | 생년월일, 기준 수명(기본 83.7세), 월 실수령액 |
| 습관, 몸 렌즈 | ⏳ | v2.1, v2.2 범위라 아직 없음 |

### 계산 규칙 (`Shared/LifeMath.swift`)

- **기준 수명:** 국가데이터처 「2024년 생명표」 기대수명 83.7세. 설정에서 바꿀 수 있습니다.
- **남은 만남:** 나와 상대 중 더 짧은 남은 기대여명 × 연간 만남 횟수.
  - 올해 1월 1일 기준으로 센 뒤, 올해 실제로 만난 횟수를 뺍니다.
  - 그래서 만나면 정확히 하나가 줄고, 만나지 못하면 해가 바뀔 때 그만큼 사라집니다.
- **노동 시간:** 가격 ÷ (월 실수령액 ÷ 209시간).

## ⚠️ 아직 검증하지 못한 것

이 코드는 **Mac이 아닌 환경에서 작성했기 때문에 아직 한 번도 컴파일하거나 실행하지 않았습니다.** Xcode에서 처음 빌드할 때 작은 컴파일 오류가 날 수 있습니다. 오류 메시지를 알려주시면 바로 고치겠습니다.

- `LifeMathTests`의 기대값은 직접 손으로 계산해 맞춰두었고, 랜딩 페이지의 계산 결과(38세 → 2,376주 등)와 같습니다.
- 위젯이 앱 데이터를 읽으려면 앱과 위젯에 같은 앱 그룹이 설정되어 있어야 합니다(빌드하기 2번 참고).
